# Openflow Run Storage Layout

## Directory Layout

```
~/.openflow/runs/<run-id>/
  metadata.json              # run-level metadata
  events.jsonl               # unified event timeline (SDK primitives)
  agents/
    <agent-name>/
      events.jsonl           # RAW agent runner output (opencode JSON stream)
```

## Run ID

Format: `YYYYMMDD-<8-hex-chars>`, e.g. `20260605-a1b2c3d4`.

Generated by the Go runner, passed to the SDK via `OPENFLOW_RUN_ID` env var.

---

## metadata.json

Written by the Go runner on completion. Replaces `metadata.json` if it exists.

```json
{
  "id": "20260605-a1b2c3d4",
  "file": "/abs/path/to/workflow.openflow.ts",
  "status": "completed|failed",
  "exit_code": 0,
  "duration_ms": 12345,
  "error": "optional error message"
}
```

---

## events.jsonl

Appended by the SDK (`sdk/events.ts`) during workflow execution. One JSON line per event.

### Event Schema

```json
{
  "type": "step|agent|shell|run_start|run_end|console",
  "timestamp": "2026-06-05T10:00:00.000Z",

  "step": "label",
  "status": "started|completed|failed",

  "agent": "agent-name",
  "prompt": "...",
  "result": "...",
  "duration_ms": 1234,

  "cmd": "echo hello",
  "stdout": "...",
  "stderr": "...",
  "exit_code": 0,

  "error": "optional error message"
}
```

### Event types

| `type`      | Mandatory fields                          | Emitted by      |
|-------------|-------------------------------------------|-----------------|
| `run_start` | `timestamp`                               | SDK on load     |
| `step`      | `step`, `status`, `timestamp`             | `step()`        |
| `agent`     | `agent`, `prompt`, `status`, `timestamp`  | `agent.run()`   |
| `shell`     | `cmd`, `exit_code`, `stdout`, `stderr`, `timestamp` | `shell()` |
| `console`   | `stdout` or `stderr`, `timestamp`         | workflow .ts    |
| `run_end`   | `status`, `exit_code`, `timestamp`        | SDK on exit     |

### Example file

```jsonl
{"type":"step","step":"GREET","status":"started","timestamp":"2026-06-05T10:00:00.000Z"}
{"type":"agent","agent":"coder","status":"started","prompt":"Say hello","timestamp":"2026-06-05T10:00:00.001Z"}
{"type":"agent","agent":"coder","status":"completed","result":"hello from openflow","duration_ms":2300,"timestamp":"2026-06-05T10:00:02.301Z"}
{"type":"shell","cmd":"echo done","exit_code":0,"stdout":"done\n","stderr":"","duration_ms":5,"timestamp":"2026-06-05T10:00:02.306Z"}
{"type":"step","step":"GREET","status":"completed","timestamp":"2026-06-05T10:00:02.306Z"}
{"type":"console","stdout":"SUCCESS: workflow completed","timestamp":"2026-06-05T10:00:02.307Z"}
```

## agents/<agent-name>/events.jsonl

Per-agent raw trace. Written by `openflow exec --trace-dir <path>` via agent-pro's `RawLog` writer.
Contains the **unmodified** event stream from the underlying agent runner (opencode, codex, cursor).
No SDK translation or synthesis — these are the actual JSON events produced by the agent.

### Example (opencode)

```jsonl
{"type":"text","part":{"text":"hello from openflow"},"session_id":"abc123"}
{"type":"tool_use","part":{"tool":"read","path":"merge.go"},"session_id":"abc123"}
{"type":"tool_use","part":{"tool":"write","path":"merge.go"},"session_id":"abc123"}
{"type":"text","part":{"text":"Fixed the recursive merge."},"session_id":"abc123"}
```

### Agent Name

If `new Agent({ name: "coder", systemPrompt: "..." })` is used, the directory is `agents/coder/`.

If `name` is omitted or empty, the name is auto-derived from the `systemPrompt`:

```
slug(first-4-words-of-system-prompt) + "-" + md5(systemPrompt)[:8]
```

Example: `systemPrompt: "You are a Go programmer. Write clean code."` → `agents/you-are-a-go-programmer-a1b2c3d4/`

## Stdout Logging (Real-Time)

Critical events are printed to stderr in real-time with `[openflow]` prefix:

```
[openflow] step: GREET
[openflow] agent: coder run "Say hello"
[openflow] agent: coder done (2.3s)
[openflow] shell: echo done → exit 0 (5ms)
[openflow] step: GREET done
```

- Step events: `[openflow] step: <label>` / `[openflow] step: <label> done` / `[openflow] step: <label> failed`
- Agent events: `[openflow] agent: <name> run "<prompt>"` / `[openflow] agent: <name> done (Xs)`
- Shell events: `[openflow] shell: <cmd> → exit <code> (Xms)` / `[openflow] shell: <cmd> FAILED: <stderr>`
- Console: workflow `console.log()` and `console.error()` pass through to stdout/stderr naturally

---

## SDK Module (`sdk/events.ts`)

A shared event emitter used by all SDK primitives:

```typescript
// Emit to events.jsonl
emitEvent(event: Record<string,unknown>): void

// Emit to agents/<name>.jsonl
emitAgentEvent(name: string, event: Record<string,unknown>): void

// Print to stderr with [openflow] prefix
log(label: string, ...args: unknown[]): void
```

All writes are best-effort — errors are silently ignored (file permissions, disk full, etc.).
